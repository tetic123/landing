# Лендинг

Адаптивный одностраничный сайт с семантической разметкой, 
интерактивными элементами и анимациями.

## Демо

[Ссылка на GitHub Pages / Vercel]

## Стек

- HTML5
- CSS3
- JavaScript

## Возможности

- Адаптивная вёрстка: десктоп, планшет, мобильные
- Семантическая разметка
- Плавная прокрутка по якорям
- Интерактивные элементы: меню, кнопки, формы

## Что реализовано

- Вёрстка по макету Figma с использованием Flexbox и Grid
- Мобильное меню-бургер
- Обработка событий через JavaScript
- Кроссбраузерная проверка

## Запуск

Откройте `index.html` в браузере.
